## Challenge 证据

新增 `internal/api/challenge_http_acceptance_test.go` 通过真实 loopback HTTP、独立 SHA-256 PoW 求解器及 SQLite 完成 8 个场景：PoW-only、算术题、图片题、站点冲突不消费、答错终结、Origin 冲突不消费、空池 503 后补题恢复、过期拒绝。正向场景同时验证错误 secret 不消费、challenge 重兑拒绝、response 重放拒绝。

浏览器在隔离的本轮实例中使用生产图片 worker 实时生成的题面，实际输入答案、运行 Worker PoW 并兑换。最终二进制还验证了首次业务提交 HTTP 201、同 token 重放 HTTP 409、业务表只新增一行、reset 清图清 token、refresh 恢复、标签点击聚焦、错误答案后禁用提交。页面脚本 fetch 用于保持同一 token 做业务重放，GUI 作答和实际网络请求分别在收据中说明。另一次原生表单流程验证未完成验证时 HTTP 403 / 零写入，完成验证后 HTTP 201。浏览器自动化读取图片不属于真人可读性研究或抗 OCR 效果认证。
