这一模式不显示标准答案，只记录你每次提交的结果（由服务端判分给出）。 它测量的是"人能不能读出来"，与 OCR/模型无关，也不会把答案回显给页面。

无障碍与诚实边界（请先读）
  • 本页的题目是纯视觉的：对无法看图或低视力的用户，这道题本质上不可完成。 这里没有音频或文本等价通道。
  • PoW-only 模式不是"等效替代"：它换掉的是"题目这一层"，防线少了一层， 安全含义与视觉题不同，不能被称为无障碍等价方案。
  • 图片 alt 只描述用途，不含答案。表单可用键盘完成（Tab → 输入 → Enter）。
  • 本页不构成完整跨站点 SDK API，也未做完整无障碍合规验证（阶段 4 的 widget 才做）。
